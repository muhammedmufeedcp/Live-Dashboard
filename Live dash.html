How to Embed Your Report

  1. Publish your report from Power BI Desktop to the Power BI Service.
  2. Open the report, then choose File → Embed report → Publish to web (public).
  3. Copy the link or the iframe code and paste the link above, or into your own site.
  4. Only use Publish to web with data that is safe to share publicly.
